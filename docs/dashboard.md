# Offline evaluation dashboard

Run from the repository root after installing the project (`python -m pip install -e .`):

```bash
python -m friendshield --evaluate examples/labeled_requests.csv --threshold 60 --output evaluation-report.json --dashboard evaluation-dashboard.html
```

Open `evaluation-dashboard.html` locally in a modern browser. No web server, account access, CDNs, or network calls are required.

The interactive slider changes the decision rule `score >= threshold` from 0 to 100. It updates confusion-matrix counts, precision, recall, F1, false-positive rate, the chart marker, and a comparison table for thresholds 30, 60, 80, and the selected value. The HTML embeds precomputed results for all 101 integer thresholds, generated by FriendShield's original Python evaluation engine. This means the dashboard does **not** change scoring rules.

**Scenario-label interpretation:** `expected_review=true` means the synthetic request was annotated as deserving human inspection, not that its account was verified malicious. At threshold 60 the included fixture has TP=4, FP=2, TN=4, FN=2, yielding precision and recall of 66.7%. The chart quantifies tradeoffs within this 12-row constructed fixture only, not operational accuracy or bot-detection efficacy.

The HTML is safe to share only if the dataset used to generate it is safe to share. Although this implementation embeds aggregate metrics rather than record identifiers, do not export proprietary or personal data. For any future real deployment, seek permission, validate representative labeled sets, quantify false-positive harm, assess class imbalance and label quality, and keep a human review process.

Errors with undefined denominators are represented as JSON `null` and displayed as N/A. Neither the HTML nor the Python command blocks or reports accounts.
